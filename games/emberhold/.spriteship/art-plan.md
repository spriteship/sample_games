# Emberhold art production

Engine: Godot 4, Compatibility renderer, 1440×900 reference viewport, angled top-down world. This is a new game alongside Last Light; its existing assets and game remain independent.

1. Project intake and saved style guide: painterly fantasy, moss/ivory/copper/amber palette.
2. Foundation collections: ten settlement buildings, twelve nature/resource props, eight ruined/hostile landmarks, four terrain materials, cinematic menu illustration.
3. Cast: Elara captain, frontier infantry, woodland ranger, ash raider, ash brute. Generate useful design variations, choose coherent best designs under delegated creative authority, then create essential walking/combat clips; share identity references only for intentional kinship.
4. Interface: resource pictograms, building pictograms, frame/panel/bar/control/indicator components via UI Packs. UI text and interactive logic are implemented in Godot.
5. Author the valley map in SpriteShip, preview, save and retain its editor link; integrate its placements and terrain into the Godot controller.
6. Polish: beacon states, citadel, additional motion, story portraits and effects where they materially improve the finished campaign.

Credit planning estimate: 8,000–18,000, with a hard 30,000 ceiling. Live server quotes and ledger totals are authoritative. Initial essential assets and complete playable campaign come first; secondary variations and richer optional motion follow only after the core works.

Verification: actual exported pixels, transparent alpha, matching camera and scale, animation quality gates and native frame order, world/UI integration, browser screenshots, collision navigation and full campaign simulation.
